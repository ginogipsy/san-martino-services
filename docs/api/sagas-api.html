San Martino — Sagas API (1.0.0)

Download OpenAPI specification:

Orchestratore di saga per coordinare transazioni distribuite tra events-service e stands-service.

sagas

Esecuzione e stato delle saga

Avvia la saga "Crea evento con cantine"

Coordina la creazione di un Event in events-service, la validazione delle cantine partecipanti in stands-service, e la registrazione locale delle partecipazioni. Compensa (delete event) se la validazione cantine fallisce.
