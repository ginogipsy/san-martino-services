San Martino — Audit Log API (1.0.0)

Download OpenAPI specification:

API di consultazione e monitoraggio per gli audit log di business di "Le cantine di San Martino". Accessibile esclusivamente agli utenti amministratori con ruolo ROLE_ADMIN.

audit-logs

Storico e tracciamento delle operazioni di business

Ricerca e paginazione degli audit log

Restituisce l'elenco paginato degli audit log in base ai filtri specificati. Richiede ROLE_ADMIN.

query Parameters
serviceId
string

Filtra per microservizio sorgente (es. stands-service, events-service)

action
string

Filtra per codice azione (es. STAND:PRICE_UPDATE, EVENT:CREATE)

userId
string

Filtra per identificativo utente / operatore

resourceId
string

Filtra per identificativo risorsa impattata (es. standId)

from
string <date-time>

Data/ora inizio intervallo temporale (ISO-8601 UTC)

to
string <date-time>

Data/ora fine intervallo temporale (ISO-8601 UTC)

page
integer
Default: 0

Numero di pagina (0-based)

size
integer
Default: 20

Elementi per pagina

sort
string
Default: "timestamp,desc"

Criterio di ordinamento

Responses

Local dev

http://localhost:8086/v1/audit-logs

Production

https://api.sanmartino.example.org/v1/audit-logs
