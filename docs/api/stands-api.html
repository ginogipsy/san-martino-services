San Martino — Stands API (1.0.0)

Download OpenAPI specification:

Gestione delle cantine (stand di cibo e bevande) della festa "Le cantine di San Martino" (Arce, FR). Ogni cantina ha proprietari e un menu (cibo + bevande).

stands

Cantine

Elenca tutte le cantine (versione summary, filtrata opzionalmente per edizione/evento)

query Parameters
eventId
string <uuid>

UUID dell'evento/edizione (es. 2026, 2025, 2024, 2018, 2014). Se omesso restituisce l'edizione corrente (2026).

includeNonParticipating
boolean
Default: false

Se true (usato dal pannello di amministrazione), elenca tutte le cantine anagrafiche anche se non ancora iscritte all'eventId selezionato.

Ricerca intelligente cantine e piatti per nome, parole chiave e descrizione

Cerca tra tutte le cantine e i rispettivi piatti/bevande sfruttando il nome del piatto, le parole chiave (keywords, es. pasta, primo, sugo, guanciale) e le descrizioni IT/EN, ordinando i risultati per rilevanza (score) e disponibilità.

query Parameters
q
string

Testo ricercato (es. "pasta", "amatriciana", "guanciale", "tartufo")

kind
string (MenuKind)
Enum: "FOOD" "DRINK"

Filtra i piatti corrispondenti per tipologia (FOOD o DRINK)

onlyAvailable
boolean
Default: false

Se true, considera solo i piatti con porzioni disponibili (availablePlates > 0)

lat
number <double> [ -90 .. 90 ]

Latitudine utente (opzionale) per boost di vicinanza GPS a parità di rilevanza

lng
number <double> [ -180 .. 180 ]

Longitudine utente (opzionale) per boost di vicinanza GPS a parità di rilevanza

eventId
string <uuid>

UUID dell'evento/edizione su cui effettuare la ricerca (default edizione corrente 2026)
