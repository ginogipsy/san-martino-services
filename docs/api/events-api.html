San Martino — Events API (1.0.0)

Download OpenAPI specification:

Gestione delle edizioni della festa "Le cantine di San Martino" (Arce, FR). Un Event rappresenta una singola edizione (es. "San Martino 2026").

events

Edizioni della festa

Elenca tutte le edizioni

query Parameters
status
string (EventStatus)
Enum: "UPCOMING" "PAST"

Filtra per stato (UPCOMING, PAST). Se omesso, ritorna tutto.

Responses

http://localhost:8081/v1/events
